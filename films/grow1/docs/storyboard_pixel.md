# 《长高一倍》像素版：逐句分镜（草稿，等用户批准）

依据：配音、时间线、数字都是定稿（`pilot_short_1_v2.md`、`narration.lock.json`），总长 39.97 秒。下表每一行钉在配音的实测说话时间上（秒，片子时间）。
样帧见 `pixel_samples/`：A 楼的剖面、B 5 楼窗口近景、C 街上看楼；角色表 `cast.png`。

## 版式（三个方向共用）

- **画布：** 原生竖屏 1080×1920。场景画在 180×320 的像素画布上，整数 6 倍放大（每个美术像素是 6×6 个屏幕像素）；近景镜头把场景放大成 12 倍，界面仍是 6 倍。
- **比例（和稿子的数一致）：** 1.7 米的人高 28 美术像素（约 16.5 像素/米），一层楼 3 米 = 49 像素，第 3 天 13.6 米的"你" = 8 倍 = 224 像素，头顶落在 5 楼（12–15 米）。
- **底部面板（像游戏对话框）：** 左边核算员的半身像，上面一行红字状态（第 N 天 · 身高 · 头顶 N 楼 · 体重 ×N），中间中文字幕，下面英文小字。面板在屏幕 y 1332–1548，留在抖音安全区里（y 150–1560、x ≤ 930）；面板以下是街面，被抖音底部文案盖住也不要紧。
- **上方留给场景。** 楼层号直接写在房间里。
- **角色：** Q 版 2.6 头身，深色描边；表情靠眼睛和嘴的几种像素形状，加头上的气泡「？」「！」「……」。核算员戴眼镜、面无表情，每一天由她盖章。
- **节奏规则（来自调研）：** 第 1 秒内画面必须有变化；5 秒内出现第一个邻居的反应；任何镜头静止不超过 3 秒；每一步换一次景别或镜头。

## 要用户定的

1. **主镜头用哪个方向：** A 剖面（看得见每层楼里的人，最好讲清楚"头顶到几楼"）；C 街上看楼（更像真实场景，邻居扒窗）；B 只用在 g5b 的近景。我的建议是 A 和 C 交替、B 做近景，也就是上表的写法。
2. **核算员的位置：** 现在是底部面板里的半身像，加每天盖章；也可以让她全身站在场景里（例如在楼前举牌）。
3. **英文字幕：** 保留（现在的样帧有），或者去掉，好让面板更大。
4. **像素字体：** 样帧里的字是 Noto Sans（不是像素字）。换成开源像素中文字体（例如缝合像素体，OFL 许可）要下载字体文件，需要你同意。
5. **开头：** 普通版、钩子版，或两版都做。
