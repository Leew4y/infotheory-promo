## 4. 在 Mac 上改了什么

1. **音效时刻。** 仓库里原来那版混音用的是暂定时刻：第 2 天的盖章声比画面上的计数器早约 1.2 秒。现在按画面的时刻重做了音效，并重新混音。配音没有动。
2. **「1 个」闪回**（独立审片建议 1）。叠到 7 个时，「1 个」在 33.20–33.27 秒又淡淡出现了 3 帧。已改：两个标签分开淡入淡出。
3. **尾卡停留时间**（建议 2）。核算单原来完整显示约 1.0 秒。现在画面从 35.53 秒起不再变化，到 37.0 秒结束，停留 1.47 秒（逐帧差分实测），和稿子写的 1.5 秒一致。片长从 36.5 秒变成 37.0 秒。
4. **字幕折行。** 一条字幕折成两行时，第一行行尾的「，」「：」去掉了，换行本身就是停顿（AGENTS.md 的展示标点规则）。改到的是 s1-4 和 s1-10。
5. **工具。** `tools/grow1/` 里写死的 Windows 路径都改成了仓库内的相对路径。在 macOS 上，Pillow 要从 Homebrew 加载 fribidi，合成脚本和重建脚本已经设好。新加了 `covers.py` 和 `cover_scene.ts`，用来做封面。重建一条命令跑完，约 67 秒：

   ```bash
   ~/envs/research/bin/python tools/grow1/rebuild.py out/grow1_vertical_v1.mp4
   ```

### 独立审片的建议里没有改的

- **计数器在画面左上，不在顶栏中间**（建议 3）。交接说明第 3 节写的是"图片里左上角大计数器"，照交接说明做。
- **「再翻一倍」的盖章在句子念完后才落下**（建议 4）。音效的规则是不压在音节上。句子前面的空隙已经被上一句压力表的滴答占了，所以盖章放在句子后面的停顿里，比句尾晚 0.1 秒。
- **刻度数字在三次镜头拉远时有重影**（建议 5）。这是引擎的运动模糊，每次只有 0.5–0.8 秒；缩到竖版的 0.56 倍后，在手机上几乎看不出。
- **问号看起来是半角**（建议 6）。源文件里是全角「？」（U+FF1F），只是这个字体的字形像半角。
- **每句中文下面有一行英文**（建议 7）。这是频道竖版合成脚本的固定格式，第五到七部都这样。

### 独立审片的意见，供用户判断（没有改）

- 尾卡四行约 75 字，在手机上一两秒读不完。置顶评论里有同一份核算单。
- 几个小标签在手机上很小：参照"你"头上的「1.7 米」、刻度数字、「今天 = 1」。
- "骨头"两个字屏上和配音里都没有出现，截面只写「截面」；简介和置顶评论里写了骨头。
- 数字写法不统一：字幕"8 倍"和"两倍""七个"混用，画面写「7 个」。这些字幕来自定稿的 narration.json，没有改。
- 英文 "Twice is you today carrying another you." 读起来别扭。
- 配音说"背着"，画面画的是骑在肩上。
