## 第 1 轮

命令：
```bash
just check                      # 通过
just check-imports              # PASS，64 个文件，0 错误
just fonts math-lessons         # 三个风格的子集；vigil：XiaoWei 覆盖 481/492，Noto Serif SC 490/492，其余落到 STIX（validate 无缺字）
just validate math-lessons      # 第一次：22 个错误（见下），修正后 0 错误、1 个警告
just sheet math-lessons --style vigil --times 4,14,23.5,40,60.5,76.5,90.5,115,135.5,159.5,175,197,221,261,276,293.5
```

validate 第一次的 22 个错误与修正：
- `numbers`：1940 与 1947 两个刻度太近，注文重叠（三个风格都报）→ 1947 的年份与注文都放到轴线上方。
- `numbers`：公式 M^φ(n) 的上标与 M 重叠 7 px → 上标右移。
- B 方向 `withdrawal`：长标注伸进右侧方块阵，对比度 1.45 → 所有标注拆成两行，不再越过右栏。
- C 方向 `release` / `withdrawal`：大号序数越过 5% 安全线 → 序数偏移改为页边内 34 px。
- 剩下 1 个警告：C 方向片尾索引的第 16 号在淡入中途（alpha 0.74）对比度 3.62；淡入结束后为 5.0 以上。只影响未选定的 C，记录不改。

## 配乐（第 1 轮）

命令：`just cues math-lessons`（50 个音效）→ `just music math-lessons`；我听不到声音，只做了数值检查（一次性脚本，按场景算 RMS 与 200–1000 Hz 能量占比）。

- 第一次：开场（invocation −15.5 dBFS、title −14.2）是全片最响的部分，与设计（只有结尾起势）相反；连祷里的单音铃落在人声频段（defenders 该频段占 84%）。
- 修改：开场持续音与低音减弱；单音铃移高两个八度（`UP = 24`）；结尾的和弦换到高八度、弦乐降低并加低通。
- 第二次：invocation −19.0、title −17.1、defenders −17.6、fire −18.3、其余 −18 到 −21 dBFS；母带 −16.00 LUFS，true peak −2.50 dBTP。
- 未解决：持续音的泛音仍让 200–1000 Hz 占比在多数场景达 20–70%。母带被 `synth.render()` 统一到 −16 LUFS，"比参考片低 3 dB"在配乐里做不到——
  人声到来后需要在混音阶段（阶段 2b）给音乐做闪避，这一点写进 sound.md 的待定项。
- 未验证：主观听感（没有人听过）。

## 导出与性能（第 1 轮后）

- `just export math-lessons 4 18`（默认风格 vigil，带配乐）：8,925 帧，14.1 分钟，平均 **10.7 帧/秒**（4 个 worker，RTX 3060 Laptop，ANGLE/D3D11），
  输出 `out/math-lessons/math-lessons.mp4`，1,354.5 MB，音轨 297.500 s。
- 码率很高（约 36 Mbps）：全片有颗粒（grain 0.035–0.05），crf 18 下颗粒很费码率。成片若需分发，可另出一个 crf 23 的版本；未做。
- 每帧开销没有逐场测；推测主要来自全幅页的着色器（6 层 fbm + 三圈花瓣）与 motion blur 的 3 个子帧。
- `just regress math-lessons`：三个风格都还没有基线（按 skill，等 Develata 认可外观后再录 vigil 的基线），所以 regress 目前不能作为通过项。
