# 声音设计与配乐方案（sound v0）

工具：`audio/synth.py`（库，不改）+ 本片的 `films/math-lessons/score.py`（片内乐器写在 score.py 里）。命令：`just cues math-lessons` → `just music math-lessons` → `just all math-lessons`。
目前没有人声轨（阶段 2b）；配乐按"将来会有人声"来留空间：人声所在的 200–1000 Hz 不放持续的中频旋律，旋律只在句间与章间出现。

## 总体

- 调式：D 多利亚（D Dorian），60 BPM。不用功能和声的进行，用持续低音（D2 / A2 的空五度）上的长音与偶发的钟声——礼拜式的"持续音 + 诵读"。
- 乐器：管风琴般的长音（`bed` / `strings`，滤得很暗）、低音 `sub`、`cello` 的长音、`felt` 钢琴单音作钟、`chime` 作序数之钟。无鼓。
- 动态：全片只有一次真正的起势——第 14 场"递火"的结语。其余都克制。
- 混音：音乐整体比 infotheory 低约 3 dB，为人声留出空间；`render()` 的母带处理照用。

## 三个声音记号（服务于"标明类别"）

这是本阶段的第二个想法：**让观众用耳朵也分得出哪句是可查的事实，哪句是主张。**

| 画面记号 | 声音 | 用在哪里 |
|---|---|---|
| 序数（1–18） | 序数之钟：`chime`，音高随序数在 D 多利亚音阶上逐级上行（1 = D5 … 18 = 高两个八度附近，超出时回落一个八度），很轻 | 每个事实句的第一段字幕出现时 |
| ◇ 复沓句（四句"不等于"） | 同一个低音：`low`，D2，2.5 s | 第 6、8、10、12 场的复沓句；第 14 场的四次"答出" |
| ◇ 反方 | `low`，A1（比复沓句低四度），1.8 s，更暗 | 每段反方开始时 |

随笔的句子没有钟，只有 `breath`——它是一个"声音"，不是证据。

## 等时的节拍器（本阶段的出人意料的想法，见 visuals.md）

第 4 场的三颗珠子沿摆线下滑，**到达最低点的间隔正好是 2 拍（2 秒）**：由 F-M03，到底的时刻是放手后 π√(r/g)，往返一次到底两次，间隔 2π√(r/g)。
取 2π√(r/g) = 2 s，即 √(r/g) = 1/π；画面上 r 取像素值，g 由此反推（g = π²·r，单位是像素/秒²）。
珠子每次到底，配一声 `tick`，落在第 1、3 拍上；同一时刻，配乐的低音换音。数学事实在打拍子——Fontenelle 说摆线会"把时间的测量推到最高的精度"，这里它为影片计时。

## 逐场

| 场景 | 配乐 | 音效 |
|---|---|---|
| invocation | 只有 D2 持续低音（`sub` + `bed` [38, 45]），从无到有 6 s | 0.0 `swell`；5.8 `low` D2 |
| title | 加入空五度 `strings` [50, 57, 62]，很暗 | 0.3 `chime` D5 |
| fontenelle | `bed` [38, 45, 50] 持续 | 序数之钟（1） |
| cycloid | 同上；9.0 s 起低音随珠子到底在 D2 / A1 间交替 | `tick` × 2；序数之钟（2、3） |
| defenders | `felt` 单音 D4、F4、A4 随三行名单；Hardy"不。"处全部停住 1 拍 | 每行 `ink`；"不。" `stamp`（gain 0.5）；序数之钟（4、5、6） |
| numbers | 低音转到 C2（多利亚的 ♭VII），复沓句处回到 D2 | 复沓 `low` D2；序数之钟（7） |
| release | 持续音变亮：加 `strings` [62, 69] | 计数 `tick` 串（gain 0.3）；序数之钟（8、9） |
| needed | 回到暗的 `bed` | 反方 `low` A1；复沓 `low` D2；序数之钟（10、11） |
| statement | 低音停在 A1（悬而未决），(C) 格亮起时 `felt` A4 | `tone`；序数之钟（12、13） |
| dispute | 三栏各一个 `felt` 单音（E4、G4、A4），分歧句处空五度回来 | 反方 `low` A1；复沓 `low` D2；序数之钟（14） |
| withdrawal | 低音下行 D2 → C2 → B♭1（数字倒退时） | 三声 `stamp`（gain 0.3）；序数之钟（15） |
| kernel | 极暗的 `bed`，`⊢ False` 散开时 `swell` | 复沓 `low` D2；序数之钟（16、17） |
| voice | 去掉持续低音，只剩高处的 `strings` [74, 81]——随笔的声音悬在空中；反方处低音回来 | 0.0 `breath`；反方 `low` A1；序数之钟（9） |
| fire | 低音回到 D2；结语处全体起势：`strings` [50, 57, 62, 66, 69]（D 大三和弦，多利亚里借来的明亮的三音）+ `cello` D2 + `felt` 和弦；最后留在空五度上 | 每次"答出" `low` D2；结语 `swell` 6 s；序数之钟（18） |
| index | 空五度慢慢收尾，最后 2 秒静 | 0.5 `chime` D5 |

## 片内乐器（写在 score.py 里，不改 synth.py）

- `verse_bell(t, n)`：序数之钟，包一层 `synth.fx_chime`，按序数算音高。场景里用 sfx 名 `chime` 加选项 `midi` 传音高（`place_cues` 已支持 `midi` 选项）。
- 持续低音与长音直接用 `bed` / `strings` / `sub` / `cello`。

## 待定（第四阶段前定）

- 人声到来后，序数之钟是否与人声的第一个字冲突：需要时把钟提前 0.2 秒。
- 第 14 场的大三和弦是否"煽情"：评审时单独听，若觉得结论被音乐放大，就改回空五度。
