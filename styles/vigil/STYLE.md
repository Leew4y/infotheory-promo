# 风格：夜祷 · Vigil

> 设计说明。先写这份，再写代码；改了外观就同步改这里。拼板与评审记录在使用它的片子的 `review/` 下（films/math-lessons/review/）。

## 为谁、什么气质
- 片子与受众：《对数学，人类应从历史中得到教训》（math-lessons）；关心数学、科学与 AI 的普通观众与数学系学生。
- 三到五个调性关键词：庄重、节律、留白、世俗的仪式、理性的狂热（狂热只在形式里）。
- 参考（文字描述，不放图）：夜里的教堂中殿，只点一支蜡烛；从里面看的玫瑰窗；经文书页边的章节号。

## 色板
| 角色 | 颜色 | 理由 |

| bg / bg2（页面底） | #0F0C0A / #1C1713 | 暖黑，不是蓝黑（与 nebula 区分）；左上一团极淡的烛光 |
| fg / fg2（正文） | #EFE6D6 / #CDBEA6 | 烛光下羊皮纸的白 |
| muted（次要文字） | #A89679 | 在页面底上 ≥ 4.5:1（validate 实测通过） |
| rule（细线） | #3B3128 | 暗铜色细线 |
| accent / accent2（唯一强调色） | #E2B35E / #F2D59E | 烛金：经文编号、启应的答句、题面里的 f、被划去的手稿；作小字时 ≥ 4.5:1 |
| alt / alt2（图表次要色） | #C0504A / #5B7BC0 | 玻璃红、钴蓝：只在玫瑰窗里出现，页面上基本不用 |
| fgOnDark / mutedOnDark（全幅页文字） | #F5EEE2 / #CFC0A8 | 配合 backdrop |

## 字体
- 中文展示：ZCOOL XiaoWei（catalog 标签 zh, serif, display, elegant, gb2312），用于大字、引文、片名与随笔；它排在 Noto Serif SC 之前，罕用字落到 Noto Serif SC。
- 中文阅读：Noto Serif SC，用于字幕（`captions()` 直接指定）。展示体只给大字，字幕用阅读体，层级分明。
- 拉丁：Instrument Serif（含斜体），用于法文引文、来源标注与标签。
- 公式：STIX Two Text / STIX Two Math（φ、≡、⊢、¬、R³）。等宽：IBM Plex Mono，用于经文编号、年份与计数。

## 背景
- 页面底：暖黑，左上角一团极淡的烛光（径向渐变）；无纹理，好让细线与 18 px 的标注读得清。
- 全幅页（着色器 shader.ts）：从中殿里看的玫瑰窗，十六重对称，三圈花瓣形玻璃加一圈尖窗，细铅条分隔，每块玻璃中间一道铅线、内部有斑驳与由中向外的明暗。
  窗居中并偏上，中心在画面上部，正文落在窗心下方。
  `progress`（叙事进度 0–1）＝透光：0 时几乎全暗，1 时点亮但始终不刺眼（亮度上限约 0.5）。
  `highlight`（焦点光 0–1）＝窗心的火：本片在"把火递了出去"时点亮。
  `uTime` 只让光有一点呼吸（固定种子的噪声），窗的几何不动。

## 版式
- 页边距 170 px，右栏从 1010 px 起（`layout`）。
- 章节标签：左上，一道金色短线下写"一　无用"（中文数字 + 标题），页码"1 / 4"在右下。
- 字幕：底部居中，Noto Serif SC 34 px、字重 500；本片的经文记号画在字幕左侧页边：数字用等宽金色，◇ 为空心菱形（muted）。
- 本片约定（films/math-lessons/film.ts）：字幕的第二栏不是英文，而是经文记号；本风格只画中文。

## 动效与转场
- 场景淡入淡出 0.8 秒，经暖黑；页面推近极慢（2% 以内）。字幕淡入淡出 0.18 秒，前后句相接时不叠影。
- 节奏：慢、克制；强调靠停顿与金色，不靠动作。

## 和已有风格的区别
- paper-dawn：米色纸、锈红、黎明地平线——本风格是暖黑、烛金、玫瑰窗，明暗相反。
- nebula：冷蓝黑、无衬线、点阵与星云、发光的线——本风格暖、衬线展示体、无点阵、线不发光，全幅背景是有几何秩序的窗而不是气体。

## 明确不做
- 不让玫瑰窗在页面上出现（只在全幅页）。
- 不用饱和的大色块；不让窗的亮度盖过文字（第一轮自评后把亮度上限从 1 降到 0.5，并把窗移到文字上方）。
- 不用宗教符号（十字、圣像）；"世俗的仪式"只靠几何、光与版式。
