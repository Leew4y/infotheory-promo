# 风格：keynote（浅色发布片）

> 设计说明。改了外观就同步改这里。拼板与评审记录在使用它的片子的 `review/` 下（首个使用者：`films/tongzhou`）。

## 为谁、什么气质
- 片子与受众：产品发布式的演示片；首个用例是黑客松作品「同舟」的 2 分钟演示，给初赛评委看（电脑或手机）。
- 调性：干净、明亮、克制、讲事实、像产品发布会。
- 参考（文字描述）：苹果发布会浅色段落和产品页——大面积浅灰底、近黑粗体无衬线字、一种强调色、产品截图放在带柔和阴影的白色圆角窗口里。

## 色板
| 角色 | 颜色 | 理由 |
|---|---|---|
| bg / bg2（页面底） | `#F5F5F7` / `#E8E8ED` | 与产品前端的页面底色一致，录屏放进来不跳色 |
| fg / fg2（正文） | `#1D1D1F` / `#3A3A3C` | 近黑，不用纯黑 |
| muted（次要文字） | `#5E5E63` | 在页面底和片头的淡紫光上都 ≥ 4.5:1（`#6E6E73` 在淡紫光上只有 4.35，validate 报错后加深） |
| rule（细线） | `#D2D2D7` | |
| accent / accent2 | `#4F3BD6` / `#8B7CF6` | 产品 logo 的靛紫；作小字时 ≥ 4.5:1；全片只此一种强调色 |
| alt / alt2（图表次要色） | `#248A3D` / `#B25000` | 与产品界面的「通过」「警告」同色相，暂未使用 |
| fgOnDark / mutedOnDark | 同 fg / muted | 本风格的全幅页也是浅色，「on dark」文字与页面相同 |

## 字体
- 中文 Noto Sans SC，拉丁与数字 Inter，等宽 JetBrains Mono（来源文件名）；字重只用 500、700。无衬线、无斜体中文。

## 背景
- 页面底：纯 `#F5F5F7`，无纹理、无颗粒、无暗角（也利于压缩）。
- 全幅页（着色器）：同一灰底，顶部两团缓慢漂移的淡薰衣草紫和淡蓝紫光，向下渐白。`progress` 让光略微变宽，`highlight` 是一条很淡的地平线。逐像素抖动防止色带。

## 版式与字号
- 左右边距 150 px；录屏窗口区 x 150、y 176、宽 1620、高 680（窗口上方另有 36 px 标题栏）。
- 字号层级（1080p，由片子的 `lib.ts` 的 `T` 统一）：作品名 96、关键数字 128、页面标题 48、字幕 36、正文 24–28、注释与标签 19–22。重要信息略大，不喊。
- 章节标签：左上，靛紫两位数字 + 粗体章名 + 一道 32 px 靛紫短线；「模拟数据」统一在右上角。
- 字幕：底部居中 36 px、字重 500，进入时轻微上浮。

## 动效与转场
- 文字淡入并上浮 10–16 px；场景淡入淡出 0.45 s；页面镜头几乎不推（drift 0.012）。光标是带白边的黑色箭头，点击是一圈半透明靛紫的扩散。

## 和已有风格的区别
- paper-dawn 是暖纸、墨线、衬线和黎明；nebula 是深色星云。keynote 是浅灰底、无衬线粗体、浅色舞台，一眼像产品发布片。

## 明确不做
- 不加纸纹、颗粒、辉光、色差；不用渐变大字、发光数字；不用居中大字配渐变背景的套路；不加第二种强调色。
